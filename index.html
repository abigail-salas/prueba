Acerca de mi

HTML

HTML, siglas de HyperText Markup Language, es el lenguaje estándar utilizado para crear y estructurar páginas web. Define la disposición y el contenido de una página, incluyendo texto, imágenes, enlaces, videos y otros elementos multimedia. Es el lenguaje base que los navegadores web interpretan para mostrar el contenido de las páginas a los usuarios

CSS

CSS, o Hojas de Estilo en Cascada, es un lenguaje de diseño gráfico utilizado para definir la presentación y el estilo de documentos HTML o XML, como páginas web. Básicamente, CSS se encarga de la apariencia visual, mientras que HTML define la estructura.

GIT

Git es un sistema de control de versiones distribuido (DVCS) de código abierto, utilizado para gestionar cambios en proyectos de software, especialmente útil para equipos de desarrollo que colaboran. Permite a los desarrolladores trabajar de forma local en copias separadas del proyecto y luego sincronizar sus cambios con un repositorio centralizado.
